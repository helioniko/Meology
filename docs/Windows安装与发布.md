# 拾记 · Meology V1.0.1

## 下载和开始使用

1. 下载 `Meology-1.0.1-Setup-x64.exe`，双击并按向导安装。
2. 安装结束可勾选立即启动。以后双击桌面的“拾记 · Meology”，或在开始菜单搜索 Meology。
3. 第一次打开先展示内置使用教程，再进入可跳过的建档问卷。以后可从“管理 → 设置 → 使用教程”重新查看。
4. 在“设置 → 语言”选择中文（简体）或 English；立即生效，重启后保留。
5. 配置自己的 API 服务，或选择 DeepSeek / 豆包网页版模式。网页模式需要自行在官网发送、复制并回填整理结果。
6. 小窗发送只保存待整理输入；API 默认每小时批量提取，成功后清除原文。核心信息变更集中审核。
7. 退出：右下角系统托盘的拾记图标 → 退出。再次双击启动图标会唤回已运行的小窗。

支持 Windows 10 2004 及以上、Windows 11 的 64 位 x64 系统。内含 Python 和相关依赖，不需要安装 Python、Git、VS Code 或开发环境。安装包内含官方 WebView2 引导安装器，复用电脑已有组件；如果缺少 WebView2，需要联网由安装向导自动补齐。普通小窗空闲时不驻留浏览器进程。

## 个人数据与更新

程序默认安装到 `%LOCALAPPDATA%\Programs\Meology`。个人资料独立保存在 `%LOCALAPPDATA%\Meology`，数据库位于其中的 `data\personal.sqlite3`，备份在 `backups`。设置的“关于 Meology”可查看和打开实际数据目录。

升级：先通过托盘退出程序，再运行新安装包。使用相同应用标识覆盖升级程序文件，保留独立数据目录。结构版本仍为 SQLite v5、档案语义 v3、JSON 交换格式 v1；后续数据库升级遵循迁移和校验备份规则。

卸载：Windows 的“应用和功能”或开始菜单的卸载入口。卸载只移除程序和快捷方式，保留个人数据。重新安装可继续使用；若确实要删除全部资料，需要自己明确删除上述个人数据目录。

API 密钥使用 Windows 当前用户账户加密。数据库和 JSON 导出不依赖具体 AI 模型，密钥不包含在 JSON 导出中；把数据搬到另一台电脑后需要重新设置 API 密钥。

语言切换只改变界面，用户填写的原文、个人资料、稳定字段键及问卷选项的存储语义不会被翻译或改写。首次安装在中文 Windows 上默认中文，其他界面语言的 Windows 上默认 English。

## 上传到下载网站

只上传 `release\Meology-1.0.1-Setup-x64.exe`。可一起提供同目录的 `.exe.sha256` 校验文件和 `release-manifest.json`。这是正式安装包，不需要上传源码、依赖文件夹或便携压缩包。

发布包不包含开发电脑的个人数据库、API 密钥、聊天输入、备份或测试资料。安装后每位使用者建立自己的数据库并设置自己的 AI 服务。当前包未做发布者代码签名；从网络下载运行时 Windows 可能显示未知发布者提示。对外规模分发前可另行配置发行者证书签名。

可用介绍：
> 拾记 Meology V1.0.1：在桌面随手记录事件和想法，按周期提取关键信息，逐步建立本地个人档案。支持日程、核心变更审核、中文 / English 和自定义 AI 服务，也可通过 MCP 只读查询或复制相关背景供其他 AI 使用。

## 开发者重新构建

在 Windows x64 使用 Python 3.12 创建隔离环境，然后运行：

```powershell
python -m venv .local-cache/build-venv
.local-cache/build-venv/Scripts/python.exe -m pip install -r packaging/requirements-build.txt
.local-cache/build-venv/Scripts/python.exe packaging/build.py
```

构建脚本在项目缓存中下载并校验官方 Inno Setup 编译器和 Microsoft WebView2 引导组件，检查数字签名，生成独立应用再编译安装包。构建物和个人数据不进 Git；构建脚本不会上传或发布任何内容。

V1.0.1 已使用临时数据库完成数据回归、双语页面、原生小窗和打包程序验证。按用户要求，交付后删除测试脚本、内置测试入口及测试产物；历史测试代码可从旧 Git 版本找回。构建时的常驻路径不会导入 WebView2；仅打开管理界面时启动独立进程。
